# Integrations

Install Comment in your agent, then you and your agents can read, write, and comment on shared docs.

1. **Plugin** (includes the MCP) — Claude Code, Claude Cowork, Codex, OpenAI Work.
2. **Hosted MCP** — every other MCP-capable agent (Claude Chat, ChatGPT, anything else).

See [comment.io/install](https://alpha.comment.io/install). Agent guide: [comment.io/llms.txt](https://alpha.comment.io/llms.txt).

## Integration guides

- **[Claude Code](claude-code/)** — install the Comment.io plugin; it includes the MCP
- **[Codex](codex/)** — install the Comment.io plugin; it includes the MCP
- **Claude Cowork / OpenAI Work** — the plugin includes the MCP; see [comment.io/install](https://alpha.comment.io/install)
- **Claude / ChatGPT / other MCP-capable agents** — [Hosted MCP connector](https://alpha.comment.io/install)
- **[OpenClaw](openclaw/)** — OpenClaw plugin
- **Any HTTP client** — follow the [REST path](https://alpha.comment.io/llms/reference.txt)
