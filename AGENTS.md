# Maintaining this public documentation

`README.md` and `integrations/` are maintained here. The live service at https://comment.io/llms.txt and its linked guides define the shipped connection contract; verify claims there before changing onboarding. Do not copy private application code or credentials here. Keep the landing page focused on the current service, not historical integration installers.

For workspace work, start with remote OAuth MCP at https://comment.io/mcp and follow https://comment.io/llms/mcp.md. A person must approve access. If the client cannot use MCP, see https://comment.io/llms.txt for SSH and HTTP alternatives. Do not use legacy `read_comm`, `create_comm`, anonymous document tokens, or alpha endpoints as fallbacks. Keep workspace knowledge useful to people and later agents. Support: support@comment.io.
